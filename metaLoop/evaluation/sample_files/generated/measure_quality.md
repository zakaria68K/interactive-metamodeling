The system shall manage collections that group related informational elements, ensuring each collection possesses a unique identifying name. Within these collections, there must be subcollections that are also distinctly named and associated with exactly one parent collection, establishing a hierarchical organization. Each subcollection can contain multiple individual data points, with each data point associated with precisely one such subcollection.

Each data point holds a unique name within its subcollection and belongs exclusively to one category that classifies it according to its nature. The system shall support various kinds of data points distinguished by the type of numerical value they capture. Some data points record whole numbers, others store numbers with decimal precision, and a different kind represent values expressed as fractions out of 100, indicating a proportion or rate.

The system shall ensure that every collection of data points within a subcollection is accessible and properly categorized to facilitate querying and reporting. When numerical data is recorded, the system must store both the value and its type to enable correct interpretation and processing. It must be possible to add new categories dynamically, and each category may encompass multiple data points, whereas each data point is tied to exactly one category.

Further, the system shall maintain clear associations between collections, their subcollections, and individual data points, preserving the integrity of these relationships. The structure shall prevent orphaned data points or subcollections and support consistent navigation from the highest-level group of data elements down to individual recorded values with their corresponding categories and types.

The system shall manage a structured collection of data stores, each uniquely identified by a textual label. Within each data store, there shall be multiple organized groupings of data records, each distinguished by a unique textual identifier within the context of its data store. Every data grouping must include one or more distinct data fields that define the type and nature of information to be stored.

Each data field within a grouping shall have a unique textual name and a specific type that dictates the nature of its values. Some data fields must be restricted to store only whole numbers, while others must be constrained to a predefined set of discrete textual choices representing possible values. The predefined sets of allowable values must be managed as collections, each containing two or more individual selectable elements. These collections of selectable options are used exclusively by the fields that require constrained textual choices.

The system shall enforce that each data grouping belongs to exactly one data store and that each data field belongs to exactly one data grouping. Data fields of the whole-number type do not require an associated collection of selectable values, whereas fields constrained to fixed choices must reference exactly one such collection. Each collection of selectable choices includes one or more individual selectable elements, each characterized by a textual value.

The system must provide the capability to create, modify, and delete data stores, their contained groupings, fields, and collections of allowed values. When a field is designated as constrained to a set of allowed textual choices, the system shall ensure that any data entered conforms to one of the specified options in the associated collection. The unique textual identifiers and names across all these elements facilitate unambiguous reference and management throughout the system's lifecycle.

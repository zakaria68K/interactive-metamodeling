The system shall manage a collection of data structures that organize information into rows and columns. Each data structure must have a unique identifier to distinguish it from others. Within each data structure, there shall be one or more fields arranged vertically, each possessing a unique name within that structure to ensure unambiguous reference. Each field must be associated with exactly one classification that constrains the kind of values it can hold, such as numeric, textual, or date-related data.

The system shall ensure that every classification has a specific definition that dictates the format and allowable values for the fields using it. This allows the system to enforce data validity during input or retrieval operations. No field may exist without an associated classification, and classifications themselves may be shared across multiple fields in different data structures.

Users shall be able to create, modify, and delete these data structures and their fields, including assigning or changing the classification of any given field. The system must maintain the integrity of the relationships between data structures and their fields, ensuring that removing a data structure also removes all its associated fields. Similarly, deleting a classification must only be permissible if no fields are currently associated with it.

When accessing or manipulating data, the system shall use the unique names of data structures and their fields to retrieve or update values. The system shall provide mechanisms to list all fields within a data structure along with their classifications and to identify all data structures containing fields of a particular classification.

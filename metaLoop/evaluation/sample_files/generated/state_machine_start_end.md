Vending Machine – Operational Flow

The machine waits at an idle screen until a coin is inserted. Once a coin arrives it moves to the item-selection screen. When the customer picks an item, the machine checks whether the deposited amount covers the item's price before proceeding — if it doesn't, it stays on the selection screen and prompts for more money.

Once the amount is sufficient, the machine drops the item into the tray and issues any change automatically. Both steps run in sequence before the machine returns to idle.

If the power supply is cut at any moment — mid-selection, mid-dispense, or idle — the machine immediately enters an "out of service" screen. It accepts no further input and shows a fault code until a technician performs a manual restart. The full coin-to-dispense cycle is isolated from this out-of-service path.
